# Escape the Checkers

A first-person pixel-art horror maze game that runs in the browser. One HTML file, no install, no dependencies.

Escape six floors, each with its own Checker and its own twist:

1. A classic maze: find the Matyas Key and unlock the Czech-xit.
2. Don't move when the warning shakes on screen.
3. The walls slowly shift.
4. A switch keeps flipping your controls.
5. An alarm gives you 5 seconds to hide in a locker.
6. You are the Checker, chasing a runner.

## Controls

- **Move:** W A S D or the arrow keys (or the on-screen buttons, or click the screen: sides turn, middle walks)
- **Doors:** Space / E / the Door button, or click the door
- **Hide (floor 5):** H / the Hide button

Warning: jump scares, loud sounds and flickering lights.

## Play

Open `index.html` in a browser, or play it on GitHub Pages once the repo is published.
